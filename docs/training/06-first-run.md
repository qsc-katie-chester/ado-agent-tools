# 6. Your first run: /bpe-help

1. Open Copilot in any folder (for example `C:\Users\<you>\source\ado-agent-tools`).
2. Type `/bpe-help` and press Enter.
3. Copilot shows a table of jobs and which agent or skill fits each. Nothing is read or changed yet.
4. Also try `/gtm-help` for everyday Azure DevOps work.

## Choosing an agent

- **App:** use the agent picker and choose, for example, **BPE Readiness Checker**.
- **CLI:** type `/agent` and select it.
- Then type a normal sentence with the ID, such as `Check PBI 12345`.

## What a good answer looks like

- Every fact has a source (title, ID or link, date).
- Each statement is labeled **Confirmed**, **Conflicting**, **Inferred** or **Gap**.
- Anything that would change a system is shown as a **preview** and waits for you to say yes.

If an answer has no sources or labels, stop and tell the facilitator.
