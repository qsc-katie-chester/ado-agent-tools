# 6. Your first run: /bpe-help

1. Open the Copilot desktop app and start a new chat. Any folder or repo is fine.
2. Type `/bpe-help` and press Enter.
3. The app shows a table of jobs and which agent or skill fits each. Nothing is read or changed yet.
4. Also try `/gtm-help` for everyday Azure DevOps work.

## Choosing an agent

1. In the chat box, open the **agent picker** and choose, for example, **BPE Readiness Checker**. [PLACEHOLDER: confirm exact picker label in your app version.]
2. Type a normal sentence with the ID, such as `Check PBI 12345`.
3. Start a new chat when you switch to a different job; this keeps answers focused.

[SCREENSHOT: agent picker open]

## What a good answer looks like

- Every fact has a source (title, ID or link, date).
- Each statement is labeled **Confirmed**, **Conflicting**, **Inferred** or **Gap**.
- Anything that would change a system is shown as a **preview** and waits for you to say yes. The app may also ask you to approve each tool it uses; read the prompt, and approve only reads you expect.

If an answer has no sources or labels, stop and tell the facilitator.
