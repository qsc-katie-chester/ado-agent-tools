# 8. Give feedback or propose a change

## Quick feedback

If an agent got something wrong:

1. Copy the prompt you used and the part of the answer that was wrong (remove anything confidential).
2. On github.com open the repo > **Issues** > **New issue**.
3. Write: what you asked, what you expected, what happened. Tag Katie.

## Propose a change to a skill or agent

Skills and agents are text files. To improve one:

1. On github.com open the file, for example `skills/bpe-definition-of-ready-check/SKILL.md`.
2. Click the pencil icon, make one small change.
3. Click **Commit changes**, choose **Create a new branch and start a pull request**.
4. Describe what you changed and the prompt you used to test it.
5. Katie reviews. She approves, asks for edits, or declines. Nothing changes for others until she approves.

Full rules: [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Do not

- Remove the read-only or preview-before-write rules.
- Rename MCP server names.
- Add passwords, tokens or customer data.
