# 1. Get access to the repo

You already have a GitHub login and the GitHub Copilot desktop app, so you only need access to the team repo.

## Steps

1. Send Katie your GitHub **username** (profile picture > your name shows it).
2. Katie adds you to the repo. You get an email invitation.
3. Open the email and click **Accept invitation**.
4. Open https://github.com/qsc-katie-chester/ado-agent-tools in your browser. If you see the file list, you have access.

The repo is private. A "404" page means you are not invited yet or you are signed in to the wrong GitHub account (click your profile picture to check).

If GitHub asks you to authorize single sign-on (SSO), click **Authorize**.

**Check:** you can see the folders `agents`, `skills`, `instructions` and `docs`.
