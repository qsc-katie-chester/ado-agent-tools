# 1. GitHub account and repo access

## Get a GitHub account

1. Go to https://github.com/signup.
2. Use your work email, pick a username, and verify the email.
3. Turn on two-factor authentication: profile picture > **Settings** > **Password and authentication**.

[SCREENSHOT: GitHub sign-up page]

## Get Copilot access

You need a GitHub Copilot license. Ask Katie to confirm yours is assigned. Your company may require you to sign in through single sign-on (SSO); if GitHub asks you to authorize SSO, click **Authorize**.

## Get access to the repo

1. Send Katie your GitHub **username**.
2. Katie adds you to the repo. You get an email invitation.
3. Open the email and click **Accept invitation**.
4. Open the repo `qsc-katie-chester/ado-agent-tools` on github.com. If you see the file list, you have access.

The repo is private. A "404" page means you are not invited yet or are signed in to the wrong account.

[SCREENSHOT: repo home page with green Code button]

**Check:** you can see the folders `agents`, `skills`, `instructions` and `docs`.
