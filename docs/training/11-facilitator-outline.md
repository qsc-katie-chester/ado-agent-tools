# 11. Facilitator outline: 60-minute live session

**Audience:** PMs, Dev, QA with no GitHub or Copilot experience.
**Before the session (at least 2 days ahead):**
- Everyone already has a GitHub login and the Copilot desktop app. Collect GitHub usernames early, send repo invitations, and confirm everyone accepted (page 1).
- Git installed (page 2). Ask IT if installs are blocked.
- Insert approved MCP install details on page 5. Confirm each person can sign in to `azure-devops`, `atlassian`, `salesforce`.
- Prepare one safe sample PBI, one enhancement with a documented process page, and one short non-confidential transcript. Insert IDs on page 7.
- Test every exercise yourself the day before.
- Capture screenshots for the `[SCREENSHOT]` placeholders.

| Time | Segment | Notes |
|---|---|---|
| 0-5 | Why: goal and safety rules | Read-only until preview approved; evidence labels; show README |
| 5-15 | Setup check | Clone, run install script, `/bpe-help` (pages 3, 4, 6). Pair up anyone stuck; helper fixes after the session |
| 15-20 | Demo | Facilitator runs Exercise 1 live; point out sources and labels |
| 20-50 | Exercises 2-5 | Teams of 2. 2 Readiness (7 min), 3 Change impact (10 min), 4 UAT coverage (8 min), 5 Transcript recap (5 min). Roles can pick the most relevant: PM 2 and 5, Dev 3, QA 4 |
| 50-55 | Debrief | What was right? What was wrong or missing? Where did labels say Gap? |
| 55-60 | Feedback and next steps | Show how to open an issue or pull request (page 8); hand out cheat sheet; note update routine |

## Facilitator tips

- Stress that Copilot is a helper, and people stay accountable for decisions.
- If an agent output lacks sources, use it as a teaching moment.
- Keep a list of every setup blocker for follow-up and for improving this guide.
- Do not run write actions in the session unless using a sandbox work item.

## After the session

- Send the cheat sheet and repo link.
- Collect feedback as issues. Katie triages and approves changes by pull request.
- Schedule a 30-minute follow-up in two weeks.
