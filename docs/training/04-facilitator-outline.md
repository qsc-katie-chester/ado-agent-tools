# 4. Facilitator outline: 60-minute live session

**Before (2 days ahead):**
- Collect GitHub usernames, send repo invitations, confirm everyone accepted.
- Add approved MCP install details to the setup page and confirm everyone can sign in to `azure-devops`, `atlassian`, `salesforce`.
- Prepare a safe sample PBI, an enhancement with a process page, and a short non-confidential transcript; add them to the exercises.
- Run every exercise yourself the day before.

| Time | Segment | Notes |
|---|---|---|
| 0-5 | Why and safety rules | Read-only until preview approved; evidence labels |
| 5-15 | Setup check | Steps 2, 3 and 5 of the setup page; pair up anyone stuck |
| 15-20 | Demo | Run exercise 1 live; point out sources and labels |
| 20-50 | Exercises 2-5 | Pairs: exercise 2 (7 min), 3 (10), 4 (8), 5 (5). By role: PM 2 and 5, Dev 3, QA 4 |
| 50-55 | Debrief | What was right, wrong, or marked Gap? |
| 55-60 | Next steps | Show how to open an issue or pull request; share the cheat sheet |

**Tips:** Copilot is a helper and people stay accountable for decisions. Use any answer without sources as a teaching moment. Log setup blockers to improve this guide. No write actions except on a sandbox item.

**After:** send the repo link and cheat sheet, collect feedback as issues, hold a 30-minute follow-up in two weeks.
